Getting Started

Introduction

Dataflow is a modern, clean, and highly scalable eCommerce admin dashboard built with Next.js. Designed for performance and flexibility, it provides developers and businesses with a powerful interface to manage online stores efficiently. With a sleek UI, reusable components, and optimized architecture, Dataflow helps you build fast-loading, responsive, and user-friendly dashboards. It includes a variety of pre-built pages such as analytics, orders, products, customers, and settings — making it perfect for any eCommerce management system.

Run Project

1. Download and install Node.js and NPM : You can download Node.js from https://nodejs.org. NPM comes bundled with Node.js.

2. Purchase Item: After purchase from Envato you have folder itemname-package Extract i have folder dataflow-nextjs. You please copy file go to D:/dataflow-nextjs

3. Use cmd with Windows Terminal : Go go the folder D:\dataflow-nextjs Type command: npm install --> npm run dev

4. In your browser navigate to http://localhost:3000

5.Thats all! Now you should see your site.

For the case Visual Studio Code Open Folder Project (open Visual Studio Code) => Open Terminal (Ctrl + `) => Type command: npm i (or yarn) --> npm install (or yarn install)
